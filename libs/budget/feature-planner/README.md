# budget-feature-planner

**Tags:** `scope:budget` · `type:feature` · `platform:web`

Angular monthly budgets screen: per-category spending progress tracking with month navigation, inline budget amount editing via upsert endpoint, union handling (categories with spend-but-no-budget, budget-but-no-spend), and aggregate totals. May import `scope:budget` ui/data-access/contracts and `scope:shared` contracts/util. No server-only imports.
