# budget-core

**Tags:** `scope:budget` · `type:core` · `platform:server`

`Account`, `Category`, `Transaction`, `MonthlyBudget` entities and their repository interfaces (`IAccountRepository`, `ICategoryRepository`, `ITransactionRepository`, `IMonthlyBudgetRepository`). Framework-free — no `@nestjs/*`, `mongoose`, or `@typegoose/*` imports. May import `scope:budget` + `scope:shared` kernel/errors/util.
